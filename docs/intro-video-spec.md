# Dem∅tif 介绍视频 Spec

日期：2026-11-05  
状态：策划初稿，待确认音乐、演示能力与拍摄安排  
用途：指导介绍视频的脚本、实拍、产品录屏和剪辑；不作为功能已交付的声明。

## 目标与受众

面向有创作冲动、会哼旋律或想唱自己的歌，但不一定熟悉编曲和 DAW 的普通人。让观众看完后理解：Demotif 是一个支持音乐编辑与声音合成的 AI 音乐工作区，可以通过与 AI 制作人交流，把自己的音乐动机逐步做成 demo，也能亲自录唱、输入 MIDI 和修改音乐。

视频要让人产生“我脑子里的那段旋律，也可以试着做出来”的冲动。重点是创作者如何表达、试听和决定，而不是逐项讲解功能。

目标体验是像面对面与制作人合作：说出想法、听见变化、继续调整；准备演唱时，制作人能协助安排节拍器与伴奏。实时语音交流与录唱协作的实际展示范围，按拍摄前验证结果确定。

## 形式与核心创意

- 主片约 120 秒，横版 16:9；人物和关键操作尽量留在便于后续竖版重构的位置。
- 真人实拍贯穿，穿插清晰的产品录屏和少量字幕。气质轻快、有生活感，允许犹豫、笑场和找到感觉的兴奋。
- 一位主角、一段原创 motif、一份持续演进的工程贯穿全片。
- 同一段 motif 从清唱开始，逐步加入节奏、和弦、贝斯和人声，最后给出完整 demo 片段。观众能听见作品形成的过程。
- 情绪节奏：灵感出现 → 尝试受阻 → 开始交流 → 创作有回应 → 进入演唱 → 听见自己的作品。

核心表达：**从你脑海里的 motif，到你的第一首 demo。**

## 叙事与分镜大纲

台词为工作稿，可按演员自然表达调整；时间包含操作、试听和反应，不要求全程铺旁白。

| 时间 | 叙事目的 | 实拍 / 产品画面 | 台词与声音设计 |
| --- | --- | --- | --- |
| 0–12 秒 | 建立普通人的创作愿望 | 路上或深夜房间，主角忽然想到旋律，拿手机录下。近景拍呼吸、嘴边的轻哼、敲桌子的手。选择一个主要生活场景即可 | “你有没有一段旋律，在脑子里循环了很久？”主角哼出本片 motif，保留环境声 |
| 12–27 秒 | 说明从想法到作品的阻力 | 面对传统制作软件的空轨道停住；尝试整曲生成，连续试听几版。有的鼓点喜欢，有的人声不合适，有的偏离最初旋律。剪辑逐渐加快 | “想把它做成歌。可是，编曲不会。生成了几版，又总差一点。”音乐反复起头、被切断，形成轻微喜剧节奏 |
| 27–38 秒 | 引出协作方式 | 主角戴耳机、对麦克风说话，切入 Dem∅tif 工作区和 Producer。用真实界面建立“有人接住这个想法”的感受 | 主角：“我有段旋律，想做成一首晚上骑车会听的歌。你陪我做一下？”制作人：“唱给我听。” |
| 38–65 秒 | 展示想法能被保留和具体修改 | 录下 motif；展示录音与后续编辑。若音频转音符流程已验证，可展示对应结果。主角补几个 MIDI 音符，或直接编辑已有音符。每次只聚焦一个变化 | “最后这个音，留长一点。”修改后试听。“鼓轻一点，先别进那么满。”节奏加入，motif 仍清晰可辨 |
| 65–92 秒 | 形成全片记忆点 | 主角准备演唱，制作人协助准备伴奏和节拍器。数拍后进入录唱；真人与工程播放交叉剪辑。保留一段连续演示，以及一个自然的小失误或笑场 | “我想试着唱一遍。”“先给我四拍。”“好，准备。”咔、咔、咔、咔——伴奏进入，主角开唱 |
| 92–110 秒 | 展示创作决定与成果 | 几轮短交流，交替呈现调整、试听、人的反应。主角亲手移动 clip、弹 MIDI 或调整音符。最后留 6–8 秒给音乐和表情 | “贝斯再往前一点。”“这里空一拍。”“对，就是这个感觉。”编曲逐层展开，高潮减少旁白 |
| 110–120 秒 | 呼应开场并留下品牌 | 回到开场机位或动作：最初是轻哼，现在听见成形的 demo。尾声可用 2–3 秒展示未来 MV、音游谱面概念，并明确标注“未来探索”，随后落品牌 | “从你脑海里的 motif，到你的第一首 demo。”音乐自然收尾，出现 Dem∅tif wordmark |

### 关键场景：“先给我四拍”

这是优先保证拍摄质量的段落。观众需要看清主角提出请求、工作区准备好、数拍开始、伴奏接入、主角进入演唱的因果关系。

尽量保留一段连续录制的操作与演唱，并记录同步音频。若压缩了准备时间，应通过可辨认的剪辑表达；不要用跨时间拼接暗示未经验证的响应速度。实际录音、节拍器与伴奏的时序由浏览器音频系统执行，不能依赖模型逐拍发指令。

## 音乐与声音

- 先写一个短、好记、普通人能唱的原创 motif，再围绕它准备最终 demo 和各阶段版本。
- 曲风暂定为有律动、适合夜间骑行的流行 / 电子方向，最终由主角音域和试听效果决定。
- 最终 demo 在视频中只需呈现有完成感的段落，不必在两分钟里展示整首歌制作的全部过程。
- 保留清唱、节奏加入、和声与贝斯加入、录唱后、最终混音等可对比阶段，统一速度与调性，保证剪辑连续。
- 用声音连接场景：手指敲桌 → 节拍器 → 正式鼓组；戴耳机、按琴键、按空格等动作可以成为剪辑点。
- 旁白与制作人回应简短，试听时留空间。对白清楚，节拍器只在相关段落出现，高潮避免解说盖住音乐。
- 保存人声、伴奏、鼓、贝斯等分轨，以及现场对白、房间声，便于后期调节层次。

## 实拍与视觉方向

- 最小拍摄配置：一位主角、一个有生活感的房间、电脑、耳机、麦克风；MIDI 键盘按实际演示需要准备。手机可拍开场灵感记录。
- 基础机位：人物中景、表情近景、手部与设备特写、肩后屏幕视角；清晰的操作细节另录屏，不依赖拍摄显示器传达小字。
- 每次关键修改后回到人的反应：停下来听、跟着点头、重新唱、找到感觉时笑出来。
- 开场安静自然，后半段通过表演、剪辑密度和音乐增加能量；避免全片快切，让核心演示和最终试听有足够停留。
- 产品画面遵循现有冷灰银、蓝色操作、薄荷色播放状态的视觉体系。不要为宣传录屏临时添加假波形、假音符、装饰电平或未实现的交互。
- 片尾使用仓库现有共享 outlined SVG wordmark 的导出资产，保持 Dem∅tif 的几何、比例与单色处理，不用普通文字重排代替。配音称呼使用 Demotif。

## 功能展示与表述边界

以下是拍摄需求，不代表本文件已经验证相关能力。开拍前逐项实际走通，并决定真实演示、明确标注的交互预演，或删减镜头。

| 内容 | 拍摄前需确认 | 未就绪时的处理 |
| --- | --- | --- |
| Producer 修改音乐 | 从请求到提案、确认应用和可听见的变化，使用同一工程验证 | 缩小演示范围，保留真实确认步骤；不要把提案直接当作已生效 |
| 实时语音交流 | 输入、回应、打断、实际响应时间与录音状态能否正确配合 | 标注“交互预演”，或改用真实可用的文字交流镜头；配音对话不能冒充已上线语音功能 |
| 录唱与伴奏、节拍器协作 | 麦克风权限、耳机监听、数拍、伴奏与录音同步，录音结果可回放 | 保留可用的手动启动流程；若保留自动协作愿景，则明确标注预演 |
| MIDI 输入 | 实际设备连接、音符输入、监听及保存行为 | 改为真实可用的界面音符编辑，不将其称为 MIDI 实录 |
| 哼唱转音符 | 当前环境的分析能力、实际转换结果、修正流程 | 只展示录音，再明确切到后续编曲；不能让剪辑暗示自动转换已经完成 |
| 声音合成 | 演示使用的合成器、采样器或歌声合成能正常发声，素材与音色许可适合发布 | 使用已验证且许可合适的声音。若用歌声合成，清楚区分本人录唱与合成人声 |
| 保存与回放 | 最终工程保存后重开，关键声音和修改仍能正确回放 | 修复后再录最终演示，避免只留下无法复现的画面 |
| MV、音游谱面生成 | 仅作为后续方向，本片不要求实现 | 尾声标注“未来探索”，不制作看似已可操作的正式功能入口；时长不足时优先删除 |

对传统制作与整曲生成的描述围绕具体体验：“入门有门槛”“想保留喜欢的部分、精确改动时需要反复尝试”。可以提及 Suno 作为整曲生成的例子，但不使用“现在没有任何类似 studio”的绝对判断，也不将所有端到端模型描述为无法编辑。

产品定位可以说“把对话、音乐编辑与声音制作放在同一个工作区”。“像视频生成工作区一样持续迭代”可用于辅助解释，不需要额外插入一段行业分析。

## 拍摄准备与产出

### 开拍前

- [ ] 确定主角、拍摄场地、设备和音乐风格，按主角音域完成 motif。
- [ ] 完成最终 demo，并准备同一工程的各阶段检查点与音频分轨。
- [ ] 逐项验证上表能力，记录实际可拍范围；在分镜中标明预演和未来探索镜头。
- [ ] 为每句演示请求排练对应操作、可听见的结果和自然反应，保证修改前后差异明显。
- [ ] 测试麦克风、耳机监听、屏幕录制和现场拍摄的同步；录唱避免外放串音。
- [ ] 检查出镜素材、音色、音乐和人物授权，使用适合本次发布的素材；录屏隐藏账号、密钥和私人数据。
- [ ] 确认片尾行动入口；未确定前只落品牌，不虚构网址、开放注册状态或发布日期。

### 交付素材

- 约 120 秒主片，以及带字幕版和无字幕干净版。
- 字幕文件、独立音乐与对白音轨、关键产品录屏、真人原始镜头。
- 最终 demo 音频、可重开的工程及阶段素材清单，便于补拍和后续短版剪辑。
- 实拍和录屏原始素材保存在视频制作目录或媒体存储中，不作为源码提交；仓库保留策划与必要的素材索引。

## 成片验收

- 前 12 秒能理解主角想留下自己的旋律；前 38 秒能理解 Demotif 如何参与。
- 开场清唱和结尾 demo 的 motif 可以被辨认出来，观众能听见至少两处具体修改前后的变化。
- “先给我四拍”段落能清楚呈现请求、准备、数拍和演唱的关系。
- 对话、亲手编辑和录唱都有明确作用，主角保有创作决定权。
- 最后有 6–8 秒相对完整、少解说的音乐展示，让作品成为情绪高潮。
- 真实演示、交互预演与未来探索可区分，不把剪辑压缩的等待时间当作性能证明。
- 字幕和关键操作在目标发布尺寸下可读，音乐不遮盖对白，片尾品牌正确。
